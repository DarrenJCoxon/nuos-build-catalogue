# nuos-build-catalogue → renamed to **nuos-builder**

> **This project has been renamed to [`nuos-builder`](https://github.com/DarrenJCoxon/nuos-builder).**
> Active development now happens there. This repository is frozen.

- **New repo:** https://github.com/DarrenJCoxon/nuos-builder
- **New command:** `npx nuos-builder init`

The existing npm package `@nusoft/nuos-build-catalogue` stays published so current
installs keep working, but it is no longer maintained — please move to **`nuos-builder`**.

---

`nuos-builder` is the build harness (formerly "the NuOS build catalogue") for directing
AI agents to plan, build, verify, and remember real software — and the engine behind the
**Freehold** product series. See the new repo for full documentation.
